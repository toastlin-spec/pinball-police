# 彈珠戰警

仿台灣夜市小鋼珠彈珠台的網頁遊戲，單一 HTML 檔，雙擊就能在瀏覽器玩，電腦和手機都支援。

| 檔案 | 說明 |
|---|---|
| `彈珠戰警.html` | 3D 版（Three.js），第一次開啟需要網路載入 3D 引擎 |
| `彈珠戰警_2D.html` | 2D 版，完全離線可玩 |

## 玩法

1. 按「投珠」投入一顆小鋼珠，機台會隨機跳出倍率並點亮中獎格：
   - ×2 亮 4 格、×3 和 ×4 各亮 3 格、×6 亮 2 格、×8 和 ×10 各亮 1 格
   - 亮燈格會平均分散在 15 格裡
2. 用 +1、+10、MAX 加碼，押注最多 99 顆
3. 把拉桿往下拉再放開，彈射一顆鋼珠；拉得越多力道越大
4. 鋼珠落進亮燈格就中獎，退回「押注 × 倍率」顆，鋼珠會從出珠盤掉出來

出珠盤裡的鋼珠就是你的持有珠數，用完可以按「補珠」再領 100 顆。全部都是虛擬鋼珠，純屬娛樂、不可兌換。

## 操作

| 動作 | 電腦 | 手機 |
|---|---|---|
| 投珠／加碼 | 點按鈕，或按 Z／X（+1）／C（+10）／V（MAX） | 點按鈕 |
| 拉桿發射 | 拖曳拉桿，或按住空白鍵後放開 | 往下拖拉桿再放開 |
| 靜音 | 左上角 🔊 或 M 鍵 | 左上角 🔊 |

### 3D 版視角調整

按右上角 🎥 進入視角調整模式，可以用滑桿微調左右角度、上下角度、遠近和畫面位置，也能直接在畫面上拖曳旋轉、用滾輪或雙指縮放。內建「預設、正面、俯視、側面、近看盤面」五種視角，調好的角度會自動記住。
